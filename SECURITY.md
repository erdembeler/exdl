# Security Policy

## Supported Versions

We release security updates and bug fixes for current stable releases of EXdl.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

The EXdl team takes the security of our application and users seriously. If you believe you have found a security vulnerability in EXdl, please do **NOT** report it publicly through a GitHub issue.

Instead, please disclose it responsibly using one of the following methods:

1. **GitHub Private Vulnerability Reporting:**  
   Navigate to the [Security Advisories](https://github.com/erdembeler/exdl/security/advisories) tab on GitHub and click **"Report a vulnerability"**.

2. **Email:**  
   Send an email directly to [erdembeler@hotmail.com](mailto:erdembeler@hotmail.com) with the subject `[EXdl Security] Vulnerability Report`.

### What to Include in Your Report

To help us triage and fix the issue promptly, please include:
- A detailed description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof-of-concept.
- The affected version(s) of EXdl and macOS.
- Any suggested mitigations or patches if available.

### What to Expect

- **Acknowledgment:** We will acknowledge receipt of your vulnerability report within 48 hours.
- **Investigation:** We will verify the issue and provide regular updates on the remediation process.
- **Resolution:** Once a fix is verified, a patched release will be published, and you will be credited for the discovery (unless you prefer to remain anonymous).
